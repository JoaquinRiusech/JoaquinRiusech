## 💫 About Me:

I'm a Computer Engineering student at UADE (Argentina), with an IT Analyst degree and a background as an Electromechanical Technician.

I enjoy building software that solves real problems: from machine learning models that anticipate anomalies in industrial processes to web platforms with interactive maps and relational databases.

My electromechanical background gives me a hands-on understanding of how industrial systems actually work, and I'm especially interested in bridging that world with data, AI, and software development.

Right now I'm sharpening my skills through university and personal projects, focusing on solid data modeling, clean code, and models whose decisions can be explained.

My goal is to grow as a developer by building useful, reliable software with real-world impact.
